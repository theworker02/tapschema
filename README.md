# tapschema

Tap identifiers and schema tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tapschema/

## Install / run

```bash
git clone https://github.com/theworker02/tapschema.git
cd tapschema
node src/cli.js
node --test
```
